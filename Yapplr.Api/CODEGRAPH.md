## Summary

Yapplr.Api is a full-featured ASP.NET Core Web API backend for a social media platform named Yapplr. It provides comprehensive functionality including user authentication, post/comment/reaction management, real-time notifications via SignalR and push providers (Firebase, Expo), content moderation with AI-assisted tagging and trust scoring, direct messaging, group management, analytics (with optional InfluxDB integration), payment processing (Stripe and PayPal), and an admin/moderation panel. The project uses a CQRS pattern with MassTransit message consumers for async operations, Entity Framework Core for data persistence, Redis for caching, and is structured around a service layer with minimal API endpoints and one traditional MVC controller.
