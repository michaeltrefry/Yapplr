## Summary

Yapplr.Api is the primary ASP.NET Core web API backend for the Yapplr social media platform. It provides a comprehensive set of HTTP endpoints and background services covering user management, social posting/commenting/reactions, real-time notifications (via SignalR, Firebase, and Expo push), content moderation with trust scoring, direct messaging, analytics (backed by InfluxDB or a SQL fallback), payment processing (Stripe and PayPal), file uploads (images and videos with async processing), and an administrative control panel. The project uses Entity Framework Core for data persistence, MassTransit-style CQRS command handlers for async operations, Redis for caching, and a multi-provider notification architecture.
