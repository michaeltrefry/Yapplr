## Summary

Yapplr.Api is a feature-rich ASP.NET Core social media platform API that provides comprehensive backend services for a Twitter/Mastodon-style microblogging application. It handles user authentication, post creation with media (images/video), social interactions (follows, reactions, comments, reposts, messaging), content moderation with trust scoring, multi-channel notifications (SignalR, Firebase, Expo), analytics via InfluxDB, and payment/subscription management via Stripe and PayPal. The project uses a CQRS pattern with MassTransit for async command processing, Entity Framework Core for data persistence, Redis for caching, and supports both controller-based and minimal API endpoint styles.
