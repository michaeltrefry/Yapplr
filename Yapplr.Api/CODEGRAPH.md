## Summary

Yapplr.Api is the core ASP.NET Core web API backend for a social media platform called Yapplr. It provides a comprehensive REST API and SignalR real-time hub supporting user accounts, posts (with media, reposts, reactions, comments, hashtags, and link previews), direct messaging, notifications (via SignalR, Firebase, and Expo push), content moderation (AI-assisted, trust-score-based, and manual admin tools), analytics (with optional InfluxDB integration), subscription/payment processing (Stripe and PayPal), and administrative tooling including audit logging and appeals. The project uses a CQRS pattern with MassTransit for asynchronous command processing, Entity Framework Core for persistence, and Redis for caching.
