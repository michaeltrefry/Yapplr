## Summary

Yapplr.Api is a feature-rich ASP.NET Core social media backend API that handles user authentication, post/comment creation, following, messaging, notifications (SignalR, Firebase, Expo), content moderation, analytics, payment processing (Stripe/PayPal), and administrative functions. It uses Entity Framework Core for persistence, a CQRS pattern via MassTransit for async command processing, Redis for caching, and InfluxDB as an optional external analytics store. The project serves as the central backend service for the Yapplr platform, exposing REST endpoints and a SignalR hub consumed by client applications.
